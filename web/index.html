Import transcript files

Use UTF-8 .txt, .srt or .vtt exports. Original text is preserved. Subtitle cue times can link to attached audio; check alignment against the original recording. TXT has no validated times, and written times in it are not converted to links. Speaker turns remain unavailable in these imports.

MacWhisper connection

MacWhisper documents TXT/SRT/VTT CLI output without Pro. Use SRT without speaker detection to try the Free route, or JSON with speaker detection if your edition and model support it. Verify the installed version and formats on this Mac. Pro activation stays inside MacWhisper; this local connection has no separate API key.

On the Mac, install the command-line tool in MacWhisper → Settings → Advanced. Activate Pro in MacWhisper's own Pro settings.

Workspace backup and recovery

A full backup includes saved hearings, original transcripts, corrections, review history and managed recordings. Note JSON/Word exports are separate readable copies.

Save the backup in a separate local location. To restore, open a new empty workspace; existing hearings will never be replaced.
